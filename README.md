# 📱 Contact Management System in C

A **menu-driven Contact Management System** built using the C programming language. This project demonstrates the practical implementation of **data structures and algorithms** such as linked lists, searching, sorting, and dynamic memory allocation.

---

## 🚀 Features

* ➕ Add new contact (Name, Phone, Email)
* 🗑️ Delete existing contact
* 📋 Display all contacts
* 🔍 Search contacts using **Binary Search**
* 🔤 Sort contacts alphabetically (**Insertion Sort**)
* 🚫 Prevent duplicate contacts
* 💾 Dynamic storage using **Linked List**

---

## 🧠 Concepts Used

* 📌 Linked List (Dynamic Data Structure)
* 📌 Linear Search (Duplicate Checking & Deletion)
* 📌 Binary Search (Efficient Searching)
* 📌 Insertion Sort (Sorting Contacts)
* 📌 Dynamic Memory Allocation (`malloc`, `free`)

## ⚙️ How It Works

1. The program starts with a **menu-driven interface**
2. User selects an operation:

   * Add Contact
   * Delete Contact
   * Display Contacts
   * Sort Contacts
   * Search Contact
3. Data is stored using a **linked list**
4. Contacts are sorted before applying **binary search**
5. Duplicate entries are prevented using **linear search**
